# Task 2: 旋转物体角速度拟合结果报告

## 1. 实验目的
基于视频追踪技术，提取旋转块的运动轨迹，计算其瞬时角速度 \(\omega(t)\)，并拟合其随时间变化的物理模型，以分析旋转运动的动力学特征。

## 2. 追踪与拟合方法

### 2.1 目标追踪与数据提取
* 视频源：`task_2.mp4` (1280x720 @ 30fps)
* 颜色空间：HSV 色彩空间
* 目标提取：
  * 蓝色阈值范围：`H: 90-135, S: 80-255, V: 80-255`
  * 形态学操作：5x5 椭圆核开运算 (`MORPH_OPEN`) 去除噪点
  * 轮廓筛选：选择面积最大的外接矩形，取其几何中心作为物体坐标 \((x_i, y_i)\)
* 旋转中心拟合：使用最小二乘法（SVD 求解超定方程组）拟合所有轨迹点的圆心 \((c_x, c_y)\)。
* 角度计算：利用 `atan2(y_i - c_y, x_i - c_x)` 计算角度 \(\theta_i\)，并进行相位解卷绕（Unwrapping）以保证角度连续性。
* 角速度差分：采用一阶中心差分法计算瞬时角速度：
    \[
 \omega_i = \frac{\theta_{i+1} - \theta_i}{t_{i+1} - t_i} 
\]
    对应时间戳取两帧中点：\(t_{\omega, i} = \frac{t_i + t_{i+1}}{2}\)。

### 2.2 非线性拟合模型
假设角速度随时间呈正弦周期性波动，建立数学模型：
\[
 \omega(t) = a + b \sin(c t + d) 
\]

* 参数含义：
  * \(a\)：平均角速度（偏置项）
  * \(b\)：角速度波动振幅
  * \(c\)：波动角频率
  * \(d\)：初相位
* 优化策略：
  1. 粗搜索：在 \(c \in [0.1, 6.0]\) 范围内以 0.005 为步长进行暴力搜索，对每个固定 \(c\) 将模型线性化 (\(a + B_1 \sin(ct) + B_2 \cos(ct)\)) 并求解正规方程，寻找 SSE 最小的初始值。
  2. 精拟合：利用 Ceres Solver 进行非线性最小二乘优化，采用 `DENSE_QR` 线性求解器，损失函数使用 `HuberLoss(1.0)` 以增强抗噪能力。

## 3. 拟合参数结果

经过 Ceres Solver 迭代优化，最终拟合参数如下：

| 参数 | 数值 | 单位 | 物理意义 |
| :--- | :--- | :--- | :--- |
| **a** | -1.35008 | rad/s | 平均角速度（顺时针旋转） |
| **b** | 0.55006 | rad/s | 角速度波动振幅 |
| **c** | 1.64990 | rad/s | 波动角频率 |
| **d** | -2.46838 | rad | 初相位 |
| **T** | 3.80822 | s | 波动周期 (\(T = 2\pi / c\)) |

**拟合方程**：
\[
 \omega(t) = -1.35008 + 0.55006 \sin(1.64990 t - 2.46838) 
\]

## 5. 结论

1. 该旋转物体做非匀速圆周运动。
2. 角速度整体为负值（约 -1.35 rad/s），表明物体主要做顺时针旋转。
3. 角速度存在明显的周期性波动，波动周期约为 3.81 秒，振幅约为 0.55 rad/s。
4. 该运动特征可能源于电机驱动中的周期性扭矩变化或重力在非水平面上的分量影响。
